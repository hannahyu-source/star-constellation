# 사계절 별자리 여행

북반구 중위도에서 계절마다 저녁 하늘에 떠오르는 대표 별자리를 살펴보는 **인터랙티브 별자리 학습 웹앱**입니다. 순수 HTML/CSS/JS 단일 파일로 동작하며 별도 서버 없이 GitHub Pages에서 바로 실행됩니다.

🔗 **라이브 데모(GitHub Pages):** https://hannahyu-source.github.io/star-constellation/

## 주요 기능

- **봄 · 여름 · 가을 · 겨울** 4계절 탭으로 이동하며 해당 계절의 저녁 하늘(9시경 기준)을 탐색
- 계절별 대표 별자리(총 19개)를 SVG 별자리 지도 위에서 확인
  - 봄: 큰곰자리(북두칠성), 목동자리, 왕관자리, 처녀자리, 사자자리 등
  - 계절별 **별의 대삼각형** 같은 주요 asterism(별자리 조합) 표시
- 별자리를 클릭하면 정보 카드에 다음 내용을 표시
  - 한글/영문 이름
  - 별자리 설명, 찾는 방법
  - 관련 그리스 신화 이야기
  - 딥스카이 천체(성운·은하 등) 정보
- 별 이름 보기 토글, 별자리 목록 리스트, 별 위치(x, y, 밝기 등급) 기반 SVG 렌더링

## 기술 스택

순수 **HTML / CSS / Vanilla JavaScript** (프레임워크·외부 라이브러리 없음). 별자리·별·신화 데이터는 `index.html` 내부에 JS 객체로 직접 정의되어 있습니다.

## 저장소 구조

```
.
├── index.html   # 앱 전체 (계절/별자리/별 데이터 + SVG 렌더링 로직 포함 단일 파일)
└── README.md
```

## 사용 방법

https://hannahyu-source.github.io/star-constellation/ 에 접속하거나 `index.html`을 브라우저로 직접 열어 계절을 선택하고 별자리를 클릭해보세요.
